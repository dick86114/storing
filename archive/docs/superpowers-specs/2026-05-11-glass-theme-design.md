# macOS Tahoe 液态玻璃主题设计

## 概述

为 Storing（乾坤戒）添加苹果 macOS Tahoe 系统风格的液态玻璃主题，作为新的配色方案选项。该主题采用蓝紫冷色调，全面覆盖所有 UI 元素，呈现通透、精致、具有层次感的视觉体验。

## 设计目标

1. 呈现 macOS Tahoe 的液态玻璃质感：多层半透明叠加、边缘光晕、内部高光折射
2. 采用蓝紫冷色调配色，契合苹果最新系统的视觉语言
3. 全面覆盖导航栏、卡片、按钮、标签、弹窗、详情面板等所有 UI 元素
4. 与现有四季主题架构完全兼容，零组件代码改动

## 技术方案

采用 CSS 变量扩展方案，在现有四季主题架构基础上新增 `glass` 配色方案。通过扩展 CSS 变量实现液态玻璃效果，无需修改任何组件代码，纯样式层变更。

## 液态玻璃效果变量

### 核心玻璃参数

| 变量 | 浅色值 | 深色值 | 说明 |
|------|--------|--------|------|
| `--glass-blur` | `24px` | `28px` | 模糊强度 |
| `--glass-saturate` | `1.6` | `1.8` | 饱和度增强 |
| `--glass-opacity` | `0.72` | `0.68` | 玻璃层透明度 |
| `--glass` | 色彩混合 | 色彩混合 | 玻璃背景色 |
| `--glass-border` | 色彩混合 | 色彩混合 | 玻璃边框色 |

### 高光与光晕效果

| 变量 | 说明 |
|------|------|
| `--glass-inner-glow` | 内部边缘高光（模拟光线从边缘折射） |
| `--glass-specular` | 顶部高光条（模拟光源照射） |
| `--glass-border-glow` | 边框外发光（强调色柔和光晕） |

### 阴影系统

| 变量 | 说明 |
|------|------|
| `--shadow-sm` | 小阴影，带紫色调 |
| `--shadow-md` | 中等阴影，玻璃特有柔和投影 |
| `--shadow-lg` | 大阴影，强调色光晕 |
| `--shadow-glass` | 玻璃层专属阴影 |
| `--shadow-elevated` | 悬浮状态阴影 |

### 圆角系统

| 变量 | 值 | 说明 |
|------|-----|------|
| `--radius` | `16px` | 基础圆角 |
| `--radius-lg` | `24px` | 大圆角（卡片、弹窗） |
| `--radius-xl` | `32px` | 极大圆角（详情面板） |
| `--radius-sm` | `10px` | 小圆角（按钮、标签） |

## 组件样式覆盖

### 导航栏（TopNav）

- 强化模糊：`backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-saturate))`
- 顶部 specular 高光条：通过 `::before` 伪元素实现 1px 白色渐变
- 发光边框：`border-bottom: 1px solid var(--glass-border-glow)`
- 添加微妙内部阴影

### 文章卡片

- 玻璃层背景：`background: var(--glass)`
- 内部高光：底部边缘微弱强调色光晕
- hover 状态：
  - 边框发光增强
  - 阴影提升至 `--shadow-elevated`
  - 微妙缩放 `transform: scale(1.02)`
  - 亮度变化 `filter: brightness(1.05)`
- 标签：玻璃胶囊样式，半透明背景 + 发光边框

### 按钮

- 主按钮：
  - 玻璃背景 + 内部高光
  - hover 时边框发光增强 + 亮度提升
- 次按钮：
  - 更透明玻璃层
  - 仅边框发光
- hover 效果：`filter: brightness(1.1)` 模拟光泽变化

### 详情面板

- 整体深色玻璃层（深色模式明显）
- 左侧边缘强调色光晕条
- 标题区 specular 高光
- 关闭按钮玻璃质感

### 弹窗/菜单

- 最强模糊：`blur(32px)`
- 边框外发光更明显
- 阴影带紫色调
- 菜单项 hover 采用玻璃高亮效果

## 实现范围

### 文件修改

1. **globals.css**：新增 `[data-color-scheme='glass']` 样式块及相关组件覆盖
2. **ThemeProvider.tsx**：ColorScheme 类型添加 `'glass'`
3. **TopNav.tsx**：COLOR_SCHEMES 数组添加玻璃选项 `{ key: 'glass', label: '玻璃', icon: '💎' }`

### 兼容性

- 与现有四季主题完全兼容
- 无组件代码改动（仅样式层）
- 支持浅色/深色模式切换
- 支持 `prefers-color-scheme` 系统跟随
