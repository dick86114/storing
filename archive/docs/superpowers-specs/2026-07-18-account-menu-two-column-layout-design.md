# 右上角账号菜单双列布局设计

## 目标

将 Storing 顶部右侧账号下拉菜单中的所有可点击选项改为双列网格，缩短菜单高度，避免较小视口中菜单内容被裁切。视觉主题的色彩、纹理、边框、悬浮态和选中态保持现状。

## 范围

- 目标组件：`apps/web/src/components/layout/DesktopTopNav.tsx` 中的 `user-menu`。
- 目标菜单项：
  - 夜昼模式：浅色模式、深色模式、跟随系统；
  - 主题风格：极简、杂志、修仙等全部风格项；
  - 账号操作：我的 MCP、用户管理、MCP 运营控制台、修改密码、退出登录，以及未登录时的登录入口。
- 用户信息区、分组标题和分隔线不属于菜单选项，继续占满整行。

## 布局

1. 使用两个独立的两列网格：夜昼选项网格与账号操作选项网格。
2. `ThemeStyleMenu` 在所有色彩风格下使用两列网格；不再只由修仙主题启用双列。
3. 每个网格单元使用 `minmax(0, 1fr)`，以保证较窄视口不会被内容撑破。
4. 下拉面板宽度受视口约束，采用 `min()` / `calc()`，使面板在小屏仍能完整显示并保持右对齐。
5. 菜单现有的键盘操作、焦点管理、点击遮罩关闭、导航和主题切换逻辑均不改变。

## 视觉约束

- 不修改任何 `data-color-scheme` 的颜色变量、背景、云纹、边框、阴影、悬浮态或激活态。
- 只新增通用的布局类和最少的尺寸规则；修仙主题原有样式继续生效。
- 危险操作“退出登录”仍使用当前危险色，只是作为网格中的一个菜单项显示。

## 验收

- 非修仙与修仙主题下，三组菜单选项均为双列。
- 管理员与普通用户、登录与未登录状态均无溢出或不可点击项。
- 在窄视口中，面板高度较改单列前缩短，且可见区域内不会横向溢出。
- 现有 Web lint 与导航结构测试通过。
