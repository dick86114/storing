# 乾坤戒（Storing）完整功能说明

> 本文仅描述产品功能、页面内容和交互逻辑，不限定颜色、字体、尺寸、布局形式、组件样式或视觉风格。可直接交给 UI 设计 Agent 作为功能输入。

## 一、产品定位

乾坤戒是一款 AI 驱动的个人稍后阅读与知识收藏工具。用户可以从网页、微信公众号、Android 系统分享或外部 AI Agent 收集文章，系统自动抓取正文和图片，并生成摘要、分类和标签。

核心流程：

**发现文章 → 提交采集 → 自动处理 → 进入个人资料库 → 阅读、收藏或归档 → 按需公开发布和分享。**

## 二、用户角色

### 游客

- 浏览系统内公开发布的文章。
- 阅读公开文章详情。
- 打开原文、复制公开链接或使用系统分享。
- 进入登录流程。

### 普通用户

- 拥有独立的收件箱、收藏、归档和发布空间。
- 采集、搜索、阅读和管理自己的文章。
- 创建和管理自己的 MCP 连接。
- 修改密码和管理个人会话。

### 服务账号

- 主要用于 MCP、外部 Agent 和自动化接入。
- 数据仍归属于对应账号空间。

### 管理员

- 拥有普通用户的全部功能。
- 管理用户、跨用户文章库、MCP 连接、调用配额和审计记录。

> 系统不提供公开注册，用户账号由管理员创建。

## 三、Web 端页面

### 1. 系统入口页 `/`

- 检查当前登录状态。
- 已登录用户进入收件箱。
- 未登录用户进入公开发布页。

### 2. 收件箱 `/inbox`

用于处理尚未收藏、尚未归档的文章。

主要功能：

- 展示文章标题、来源、发布时间、封面、AI 摘要、AI 分类和标签。
- 按“最近收录”或“最近发布”排序，并支持正序、倒序切换。
- 支持刷新和连续加载更多文章。
- 点击文章进入阅读详情。
- 收藏文章后，文章离开收件箱并进入收藏。
- 归档文章后，文章离开收件箱并进入归档。
- 检测上次保存的阅读书签，可继续上次阅读位置。
- 提供加载、空状态、加载失败和重试状态。

### 3. 收藏页 `/favorites`

展示当前用户所有已收藏文章；文章可以同时处于归档状态。

主要功能：

- 查看收藏文章及其摘要、标签、来源和状态。
- 按“最近收藏”“最近收录”或“最近发布”排序。
- 取消收藏。
- 将收藏文章归档。
- 打开文章详情继续阅读。
- 恢复上次保存的阅读书签。
- 支持刷新、连续加载、错误重试和空状态。

### 4. 归档页 `/archive`

用于长期保存和整理已处理文章。

主要功能：

- 展示全部已归档文章。
- 按文章来源筛选文章。
- 查看每个来源的文章数量。
- 对来源列表按数量、名称或最近收录时间排序。
- 来源较多时支持搜索全部来源。
- 文章可按最近归档、最近收录或最近发布排序。
- 将文章移回收件箱。
- 收藏或取消收藏归档文章。
- 打开文章详情阅读。
- 恢复上次阅读书签。
- 支持刷新、连续加载、错误重试和空状态。

### 5. 发布页 `/published`

用于浏览已公开发布的文章。

访问规则：

- 游客看到系统中全部公开文章。
- 已登录用户看到自己发布的文章。

主要功能：

- 展示文章标题、封面、来源、发布时间、AI 摘要、分类和标签。
- 显示文章已发布状态。
- 点击文章进入独立的公开文章详情页。
- 无公开文章时显示对应空状态。

### 6. 公开文章详情 `/p/[publicId]`

无需登录即可访问的公开阅读页面。

主要功能：

- 展示文章标题、来源、作者、发布时间、来源类型和 AI 标签。
- 展示可展开或收起的 AI 摘要。
- 展示已保存的正文；HTML 不可用时使用文本正文兜底。
- 返回上一级或公开文章列表。
- 复制公开文章链接。
- 打开原始网页。
- 使用系统分享能力分享文章；不支持时自动尝试复制链接。
- 阅读较深时提供返回顶部功能。
- 文章不存在、已取消发布或加载失败时显示明确反馈。

### 7. 私有文章阅读详情

从收件箱、收藏或归档点击文章后进入的阅读功能。

主要内容：

- 标题、来源、作者、时间、来源类型和地点信息。
- AI 标签。
- 可展开和收起的 AI 摘要。
- 清理后的正文阅读内容。
- 对完整网页镜像内容提供原页面还原阅读。
- 正文图片支持打开图片预览，并浏览文章中的其他图片。
- 正文暂时不可用时仍保留原文入口。

文章操作：

- 保存当前文章阅读位置和列表位置。
- 收藏或取消收藏。
- 归档或移回收件箱。
- 发布或取消发布。
- 复制原文链接、打开原文。
- 重新抓取正文。
- 重新生成 AI 摘要和标签。
- 删除当前收藏记录或归档记录。
- 彻底删除文章。

分享功能：

- 未发布文章在分享前自动完成发布。
- 可根据用户选中的正文片段生成分享海报；未选中文字时使用文章封面或正文内容生成。
- 海报包含文章信息、分享入口和二维码。
- 支持保存海报图片、系统分享和复制链接。

### 8. 采集页 `/collect`

用于手动提交网页并查看采集任务。

#### 提交采集

- 输入网页链接。
- 从系统剪贴板读取链接。
- 自动补全缺失的协议。
- 仅接受公开的 HTTP 或 HTTPS 网页。
- 拒绝无效链接、本地地址和私有网络地址。
- 微信公众号链接和普通网页使用不同的抓取流程。
- 提交后创建后台任务，用户可离开页面继续使用系统。

#### 任务记录

每条任务显示：

- 文章标题或链接。
- 当前状态和处理阶段。
- 实际使用的抓取方式。
- 采集错误摘要、详细原因和处理建议。
- 完整处理步骤。

支持的操作：

- 自动刷新运行中的任务。
- 手动刷新。
- 展开或收起任务处理过程。
- 复制采集链接。
- 失败后重新采集。
- 完成后直接打开文章。
- 删除单条非运行中任务记录。
- 清理全部已完成和失败的记录。
- 加载更早的任务记录。

### 9. 我的 MCP `/settings/mcp`

用于把乾坤戒接入 Codex、Claude Desktop、远程 SaaS 或其他 AI Agent。

#### 我的连接

- 查看自己的全部 MCP 连接及运行状态。
- 创建独立连接并命名。
- 选择“只生成摘要”或“摘要并保存文章”两类权限。
- 查看平台为当前用户设置的调用频率和并发采集限制。
- 创建成功后一次性显示 API Key。
- 复制 API Key 和完整客户端配置。
- 暂停或恢复连接。
- 轮换 API Key，旧 Key 立即失效。
- 删除连接。

#### 接入指南

- 提供远程 Streamable HTTP 接入说明。
- 提供本地 stdio 兼容接入说明。
- 展示并复制服务地址、认证方式和配置示例。
- 说明可用工具：
  - `summarize_url`：提交网页并生成摘要。
  - `get_collect_status`：查询异步任务状态和结果。
  - `collect_url`：采集网页并保存到用户资料库。
- 提示 API Key 安全和用户数据隔离规则。

#### 调用记录

- 查看自己连接的最近调用。
- 展示调用状态、工具名称、错误结果、耗时和时间。
- 区分成功、失败和被限流的请求。

### 10. 用户管理 `/admin/users`

仅管理员可访问。

主要功能：

- 查看用户总数、启用用户数、MCP 用户数和历史调用数。
- 按用户名搜索用户。
- 按角色和账号状态筛选。
- 创建普通用户、服务账号或管理员。
- 修改用户名、角色、状态和密码。
- 启用或禁用非管理员账号。
- 管理员账号受保护，不能被禁用或降级。
- 查看每位用户的注册时间、最后登录时间和最近 MCP 调用时间。
- 查看用户的收件箱、收藏、归档、MCP 连接和 MCP 调用数量。
- 直接进入指定用户的文章库。
- 查看用户的 MCP 连接状态和最近调用记录。
- 支持 MCP 调用记录分页。
- 检查并同步部署环境中配置的恢复管理员密码。

### 11. 用户文章库 `/admin/library`

仅管理员可访问，用于跨用户内容治理。

主要功能：

- 查看指定用户的个人文章库。
- 区分收件箱、收藏和归档状态。
- 按收录时间范围筛选。
- 按标题或原文链接搜索。
- 展示文章来源类型，例如网页采集、MCP、外部 Agent、系统任务或管理员副本。
- 展示对应 MCP 连接来源。
- 分页浏览文章。
- 打开原始网页。
- 将其他用户的文章复制到管理员自己的收件箱。
- 在目标用户空间内重新生成 AI 摘要、分类和标签。
- 删除目标用户的文章记录，但不影响其他用户持有的同一篇文章。
- 查看跨用户管理操作的审计记录。

### 12. MCP 运营控制台 `/admin/mcp`

仅管理员可访问。

主要功能：

- 查看系统连接总数、运行中连接数、可用用户数和最近调用数。
- 查看全部用户的 MCP 连接。
- 为指定用户创建连接。
- 自定义连接权限、调用频率和并发采集限制。
- 暂停、恢复、轮换 Key 或删除任意连接。
- 配置普通用户新建连接时采用的平台默认配额。
- 默认配额修改只影响之后创建的连接，不自动改变已有连接。
- 查看全平台 MCP 调用审计记录。
- 进入用户管理或管理员自己的 MCP 页面。

## 四、Web 全局功能

- 全局导航和各资料库文章数量。
- 全局文章搜索，搜索范围根据登录状态和数据权限决定。
- 搜索标题、来源、原始摘要、AI 摘要、分类和标签。
- 支持键盘选择搜索结果并直接打开文章。
- 登录、退出登录和修改密码。
- 用户外观偏好切换，具体视觉方案可由新设计重新定义。
- 页面切换、加载、空状态、错误、重试、权限不足和操作成功反馈。
- Web 应用支持移动设备访问和安装式 Web 应用能力。
- 所有个人文章状态、MCP 连接和管理操作按用户隔离。

## 五、Android 端页面与功能

### 1. 游客首页

- 未登录时直接浏览公开发布文章。
- 打开公开文章阅读。
- 打开原网页或分享原网页。
- 进入登录页。
- 私有资料库和管理操作在登录后开放。

### 2. 登录页

- 输入用户名和密码。
- 显示或隐藏密码。
- 展示登录中和登录失败状态。
- 登录成功后恢复用户资料库和会话。

### 3. 资料库主页

已登录后包含：

- 收件箱。
- 收藏。
- 归档。
- 发布。

页面能力：

- 搜索标题、来源、摘要或标签。
- 按当前资料库支持的时间维度排序。
- 归档页按来源筛选。
- 在两种不同信息密度的文章展示方式之间切换。
- 下拉刷新。
- 滚动加载更多。
- 网络不可用时使用本地列表缓存，并明确提示当前为缓存内容。
- 显示正在进行的采集任务数量。
- 接收其他应用分享进来的网页链接。

### 4. Android 手动采集

- 输入公开网页链接。
- 从系统剪贴板粘贴。
- 校验链接格式。
- 创建后台采集任务。
- 展示提交成功或失败反馈。

### 5. 系统分享接收页

用户从浏览器、微信或其他应用分享文本到乾坤戒时打开。

主要功能：

- 从分享文本中识别一个或多个网页链接。
- 多个链接时允许选择其中一个。
- 提交后在后台采集，并自动返回原应用。
- 无有效链接时展示错误并返回原应用。
- 网络不可用时保存待提交任务，网络恢复后自动重试。

### 6. 采集任务页

- 查看 Android 端发起的采集任务。
- 显示进行中任务数量。
- 查看任务标题、链接、状态、阶段和错误信息。
- 失败任务可重试。
- 完成任务可直接打开文章。
- 清理已完成任务。
- 查看后台运行和电池优化说明。
- 任务完成或失败后发送系统通知。
- 点击通知可进入完成文章或采集任务列表。

### 7. Android 阅读器

- 展示已保存的完整 HTML 正文。
- HTML 不可用时展示来源、标题、AI 摘要和文本正文。
- 打开原网页。
- 分享原网页。
- 登录用户可以收藏、取消收藏、归档、移回收件箱和删除文章。
- 游客阅读公开文章时只提供公开阅读和分享能力。

### 8. 设置与更新

- 查看应用版本信息。
- 切换浅色、深色或跟随系统。
- 手动检查新版本。
- 展示版本说明。
- 下载、校验并安装更新。
- 区分可跳过更新和强制更新。
- 可忽略某个非强制版本或暂不更新。
- 查看后台采集及电池优化排查步骤。
- 查看应用和服务地址说明。
- 退出当前设备并清除本地会话。

## 六、支撑业务能力

- 微信公众号正文抓取。
- 普通网页完整镜像抓取，并兼顾桌面和移动网页内容。
- 正文、封面和正文图片保存。
- AI 自动摘要、分类和标签。
- 抓取失败后的多策略重试和错误诊断。
- 文章全文搜索。
- 用户级数据隔离。
- 文章公开发布与取消发布。
- MCP 异步摘要和采集服务。
- MCP 权限、配额、限流和审计。
- Android 后台任务、离线提交和版本更新。

## 七、需要在新设计中统一表达的业务规则

1. **采集结果统一称为“保存到个人资料库”较稳妥。** 当前部分页面文案分别使用“收件箱”和“归档”，后续应统一最终落点的产品语言。
2. **收藏、归档和发布是可叠加状态。** 一篇文章可以同时被收藏、归档并公开发布。
3. **发布依赖正文和 AI 信息。** 未归档文章发布时，系统会先完成归档，并确保摘要和标签可用。
4. **分享私有文章会触发发布。** 用户应能够明确感知文章将变为公开可访问。
5. **删除分为不同层级。** 取消收藏、删除个人文章记录和彻底删除原始文章必须明确区分。
6. **游客与登录用户的发布页范围不同。** 游客查看全站公开内容，登录用户当前查看自己的发布内容。
7. 所有页面都应覆盖：加载、空数据、失败重试、无权限、操作进行中和操作结果反馈。
