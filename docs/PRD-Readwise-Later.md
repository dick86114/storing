# Storing — AI 驱动的稍后阅读平台

**产品名称：** Storing 稍后阅读
**文档版本：** v1.0
**最后更新：** 2026-05-06
**文档状态：** 初稿

---

## 1. 产品概述

### 1.1 产品定位

Storing 是一款 AI 驱动的个人稍后阅读平台，帮助用户高效管理日常收集的文章内容。核心差异化在于 AI 摘要、智能分类和自动标签系统，让用户在信息过载的环境中快速筛选、消化和归档有价值的内容。

### 1.2 目标用户

- **主要用户：** 每日阅读大量技术文章、行业分析、设计资讯的知识工作者
- **使用场景：** 浏览器中发现好文章 → 保存到 Storing → 稍后阅读 → 归档分类
- **使用频率：** 每天 2-5 篇文章入库，碎片化时间阅读

### 1.3 核心价值主张

| 用户痛点 | 解决方案 |
|---------|---------|
| 文章太多读不完 | 收件箱聚焦待处理文章，归档后从列表消失 |
| 长文没时间细读 | AI 智能摘要，快速掌握核心内容 |
| 归档后找不到 | AI 自动分类 + 标签系统 + 全文搜索 |
| 分类靠人工太累 | 归档时 AI 自动读取内容并智能分类 |

## 2. 用户故事

### 2.1 收件箱管理

```
作为一名知识工作者
我希望每天收集的文章自动进入收件箱
以便我有空时集中处理
```

**验收标准：**
- 新文章默认出现在收件箱，按日期倒序排列
- 每页展示 8 篇文章，超出时显示分页导航
- 收件箱计数实时更新

### 2.2 AI 快速预览

```
作为一名忙碌的读者
我希望打开文章时能看到 AI 生成的摘要
以便快速判断这篇文章是否值得深入阅读
```

**验收标准：**
- 文章详情页顶部展示 AI 智能摘要板块
- 摘要包含核心观点、关键论据、数据支撑
- 摘要可独立阅读，不依赖正文

### 2.3 收藏与归档

```
作为一名内容管理者
我希望对文章进行收藏或归档操作
以便区分优先阅读和已处理的内容
```

**验收标准：**
- 收藏操作：文章从收件箱移至收藏夹，支持取消收藏
- 归档操作：文章从收件箱/收藏夹移至归档，支持从归档移回
- 操作后显示 Toast 反馈提示

### 2.4 AI 智能分类

```
作为一名归档用户
我希望归档后文章能被自动分类
以便在归档列表中按类别筛选浏览
```

**验收标准：**
- 归档时 AI 自动分析文章内容并分配分类（技术、设计、AI、商业、职业、效率等）
- 归档视图左侧显示分类筛选器，带文章数量统计
- 切换分类时列表实时更新

### 2.5 标签系统

```
作为一名内容检索者
我希望通过标签快速定位同类文章
以便深入研究某个主题
```

**验收标准：**
- AI 为每篇文章自动生成 3-5 个标签
- 文章卡片展示最多 3 个标签
- 文章详情页展示全部标签，点击标签触发搜索
- 搜索支持按标签匹配

### 2.6 全文搜索

```
作为一名信息检索者
我希望通过关键词快速找到目标文章
以便在大量归档内容中精确定位
```

**验收标准：**
- 支持 ⌘K 快捷键唤起搜索
- 搜索范围覆盖标题、摘要、标签、来源、分类、AI 摘要
- 搜索结果高亮匹配关键词
- 支持键盘导航（上下选择、回车打开）

## 3. 功能清单

### 3.1 页面结构

| 区域 | 说明 |
|------|------|
| 顶部导航栏 | Logo + 搜索触发器 + 主题切换，玻璃质感毛玻璃背景 |
| 标签栏 | 收件箱 / 收藏 / 归档 三个视图切换，显示文章计数 |
| 内容区域 | 文章卡片列表 + 分页导航，归档模式下左侧显示分类筛选 |
| 文章详情 | 侧滑面板，展示元信息、AI 摘要、标签、正文内容 |
| 搜索弹窗 | 居中模态框，实时搜索 + 结果列表 |

### 3.2 功能模块

#### 3.2.1 收件箱（Inbox）

- 展示所有未归档、未收藏的文章
- 按日期倒序排列
- 支持收藏和归档操作
- 分页：每页 8 篇

#### 3.2.2 收藏夹（Favorites）

- 展示所有已收藏且未归档的文章
- 按日期倒序排列
- 支持取消收藏和归档操作
- 分页：每页 8 篇

#### 3.2.3 归档（Archive）

- 展示所有已归档的文章
- 左侧分类筛选器（桌面端）/ 横向胶囊标签（移动端）
- 支持取消归档（移回收件箱）
- 分页：每页 8 篇

#### 3.2.4 文章详情

- 侧滑面板，宽度 680px（移动端全屏）
- 内容区域：
  1. 元信息：来源、日期、阅读时间
  2. 标题（大号衬线字体）
  3. 摘要/导语
  4. AI 智能摘要（玻璃质感卡片，顶部强调色渐变条）
  5. 标签列表（可点击触发搜索）
  6. 正文内容（核心观点 + 引用 + 关键要点）
- 操作栏：收藏/取消收藏、归档/取消归档

#### 3.2.5 搜索

- 全局搜索，⌘K 唤起
- 实时搜索，输入即搜
- 搜索结果展示标题、来源、日期、归档状态
- 关键词高亮匹配
- 键盘导航支持

#### 3.2.6 主题切换

- 支持三种模式：浅色、深色、跟随系统
- localStorage 持久化用户选择
- 浅色模式：米白色纸张纹理背景 + 玻璃质感元素
- 深色模式：深灰色背景，无纸张纹理，高对比度文字

## 4. 数据模型

### 4.1 文章（Article）

```typescript
interface Article {
  id: number;              // 唯一标识
  title: string;           // 文章标题
  source: string;          // 来源平台（如 InfoQ、机器之心）
  date: string;            // 发布日期 ISO 格式（如 2026-05-06）
  readTime: string;        // 预估阅读时间（如 "8 分钟"）
  excerpt: string;         // 文章摘要/导语
  aiSummary: string;       // AI 生成的智能摘要
  tags: string[];          // AI 自动生成的标签数组
  category: string;        // AI 分类（技术、设计、AI、商业、职业、效率）
  favorited: boolean;      // 是否已收藏
  archived: boolean;       // 是否已归档
}
```

### 4.2 视图状态（View State）

```typescript
interface ViewState {
  currentTab: 'inbox' | 'favorites' | 'archive';  // 当前视图
  activeCategory: string;                          // 归档分类筛选
  detailArticleId: number | null;                  // 当前打开的文章 ID
  currentPage: number;                             // 当前分页页码
}
```

### 4.3 主题状态（Theme State）

```typescript
type ThemeMode = 'light' | 'dark' | 'system';
// 持久化于 localStorage: key = 'theme'
```

### 5.2 动效规范

| 交互 | 动效 | 参数 |

### 6.7 玻璃质感

```css
/* 玻璃背景 */
background: color-mix(in oklch, var(--surface) 72%, transparent);
backdrop-filter: blur(12px);
border: 1px solid color-mix(in oklch, var(--border) 60%, transparent);
```

应用于：顶部导航栏、搜索框、文章卡片、AI 摘要卡片、分页器、详情面板头部

### 6.8 纸张纹理

浅色模式下通过 `body::before` 伪元素覆盖 SVG fractalNoise 纹理，opacity 0.35。深色模式下关闭。

## 7. 响应式适配

### 7.1 断点

| 断点 | 宽度 | 适配策略 |
|------|------|---------|
| 桌面 | > 900px | 左侧边栏 + 右侧列表，完整导航 |
| 平板 | 640-900px | 侧边栏切换为横向胶囊标签，列表单列 |
| 手机 | < 640px | 隐藏 logo 文字和搜索文字，卡片单列，详情全屏 |

### 7.2 移动端特殊处理

- 隐藏 logo 文字，只保留图标
- 隐藏搜索按钮文字和快捷键提示，只保留搜索图标
- 详情面板全屏展示
- 卡片操作按钮从纵向改为横向排列
- 归档分类从左侧边栏切换为顶部横向胶囊标签滚动
- 页面边距（--gutter）保持 20px 避免内容贴边

## 8. 技术要点

### 8.1 前端架构

- **技术栈：** 纯 HTML + CSS + Vanilla JavaScript，单文件实现
- **状态管理：** 全局变量（currentTab, activeCategory, detailArticleId, currentPage）
- **渲染方式：** innerHTML 模板字符串，函数式渲染
- **数据存储：** 内存中的 ARTICLES 数组（原型阶段），后续对接 API

### 8.2 关键技术点

| 技术点 | 实现方式 |
|--------|---------|
| 玻璃质感 | `backdrop-filter: blur()` + `color-mix()` 半透明背景 |
| 纸张纹理 | SVG fractalNoise 作为 `body::before` 背景 |
| 深浅主题 | CSS 自定义属性 + `[data-theme]` 选择器 + `prefers-color-scheme` 媒体查询 |
| 主题持久化 | localStorage 存储用户选择 |
| 搜索高亮 | 字符串切片 + `<strong>` 标签包裹匹配文本 |
| 侧滑面板 | `transform: translateX()` + `transition` 动画 |
| 卡片入场 | `@keyframes` + `animation-delay` 依次延迟 |
| 响应式侧边栏 | CSS Grid 动态列切换 + 媒体查询 |

### 8.3 性能考量

- 单文件无外部依赖，首屏加载快
- 虚拟滚动未实现（当前数据量 30 条无需），数据量增长后需考虑
- 搜索为前端实时过滤，大量数据时需改为后端搜索
- backdrop-filter 在低端设备上可能有性能问题，需添加降级方案
